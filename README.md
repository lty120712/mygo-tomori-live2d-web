# Tomori Studio

一个跑在浏览器里的 Live2D 多模型场景与动画编辑器，支持模型素材、动作表情、身体参数、多轨关键帧和视频录制导出。

纯前端项目，不需要后端。Live2D 运行时来自 npm 上的 `l2d` 包，已经随项目一起打包，断网也能正常跑。

## v0.1

版本功能与界面优化记录见 [发布记录](docs/RELEASES.md)。

时间统一显示为“分:秒:帧”的整数时间码，例如 30 FPS 下 `00:05:08` 表示 5 秒 8 帧，不显示小数秒。时间输入框可用上下键微调一帧，Enter 或离开输入框确认；内部仍按帧定位。

当前版本为 v0.1，开发分支为 `v0.1`。V1 编辑器和旧单模型工程迁移已移除；历史版本仍保存在 `v1.0.0` 与 `v2.0.0` 标签中。

- 左侧模型素材点击添加到场景，同一模型可添加多次；每个片段独立控制。
- 模型片段有开始时间、显示时长、轨道和源时间偏移。不同轨道重叠时同屏，同一轨道前后排列时切换模型。
- 拖动时间线片段移动，拖动左右边缘裁剪；支持复制、删除和在播放头切割。切割保留源时间与内部动画。
- 上方轨道为上层，可拖动左侧图层卡片上下排序，或右键“向上一层 / 向下一层”；新建和复制模型默认插入顶层，排序支持撤销重做。
- 图层默认使用模型名称，可双击名称或通过右键菜单重命名。左侧锁与眼睛按钮可锁定、隐藏整层；锁定禁止画布拖动、片段和关键帧编辑及删除，但保持播放和导出；隐藏不参与画布及视频导出。状态随工程保存，支持撤销重做。
- 模型片段支持 Ctrl / Shift 多选、轨道空白处框选与整组拖动吸附；关键帧区域仍框选关键帧。Ctrl+C / Ctrl+V 复制粘贴整组模型到播放头，新副本插入顶层，保留时间间隔、关键帧、动作表情和源偏移；Delete 批量删除，锁定图层跳过选择，整组操作一步撤销重做。
- 时间轴右键菜单按轨道、模型片段、关键帧、动作和表情分组，显示所选数量、快捷键及禁用状态；模型多选可在播放头批量切割，关键帧可按片段、轨道或参数全选和清空。动作编辑开始时间、时长和源入点，表情只编辑切换时间。长菜单自动定位并滚动，离散菜单操作各占一步撤销。
- 点击画布或片段选中模型，在右侧编辑位置、缩放、旋转、透明度、原生参数、动作与表情。
- 画布随可用空间自适应放大；顶部「素材库」「片段属性」可收起侧栏，「放大画布」收起侧栏与时间线，「返回编辑」恢复布局。预览放大不改变录制分辨率。
- 统一播放头驱动片段显示和参数/变换插值；时间线展开选中片段的动作、表情和已编辑参数轨。关键帧支持多选、框选、拖动、复制粘贴和 Delete 删除，右键编辑。动作显示名称、进度及剩余时间；表情显示切换帧，从这一帧保持到下一表情帧，最后保持到模型离场，无时长和倒计时。两者支持选中、拖动、右键编辑、复制粘贴和 Delete 删除；动作左右边缘可裁剪源入点及出点，所有剪辑操作支持撤销重做。
- 导出完整场景工程 JSON，支持本地自动保存与恢复。沿用已有场景存储键和工程格式，版本更名不影响已有多模型工程。
- 「录制场景」导出整张 960×540 合成画布，包含所有当前可见模型及背景；选择框不会进入视频。

时间线支持 1×–16× 缩放、横向滚动和“适合全长”。移动或裁剪片段时默认吸附到播放头、其他片段边界及工程首尾；黄色线提示吸附，按住 Alt 临时关闭。Ctrl / ⌘ + 滚轮在时间线内缩放。

每个模型片段直接显示关键帧菱形：黄色为画面变换，蓝色为身体参数；同一时间的同类参数合并显示，悬停可查看参数和值。选中后用关键帧栏选择参数、查看当前值及相邻帧、前后导航、增删和编辑数值。“展开关键帧”将所选参数及已有动画参数显示在模型轨道下方，支持拖动调整关键帧时间、右键编辑或 Delete 删除，编辑可撤销。关键帧不会再只藏在所有模型轨道的底部。

关键帧支持矩形框选及 Shift / Ctrl / ⌘ 追加多选，Delete 批量删除并可一次撤销。右键关键帧打开编辑菜单（不会立即删除），可编辑数值、时间及缓动；多选可批量设置缓动。右键模型轨道、片段或参数轨提供全选及删除该范围全部关键帧，包含裁剪隐藏的帧。关闭“框选”后，轨道空白处恢复拖动播放头。

本阶段已完成场景与多轨编辑基础、撤销重做、吸附和时间线缩放。动作事件按播放头触发，SDK 实时动作还不支持任意时间精确采样；动作精确跳帧、音频多轨尚待实现。详细约定见 [v2 开发计划](docs/V2_PLAN.md)。

## 快速开始

```bash
npm install
npm run dev        # 打开 http://127.0.0.1:5173
```

Windows 上也可以直接双击 `start.bat`，它会启动服务并自动打开浏览器。

其他命令：

```bash
npm run build      # 产出 dist/
npm run preview    # 本地预览构建结果
```

## 快捷键

顶部「？说明书」提供完整快捷键与操作说明。空格播放／暂停，Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Delete 删除所选项目；时间线左右键逐帧定位或移动所选关键帧，鼠标中键拖动画布视野。

## 模型资源怎么放

模型按 `public/models/<角色>/<模型名>/` 组织，例如 `public/models/tomori/live_default/`。构建和开发时插件会扫描这个目录，按下面的顺序寻找入口文件：

1. `<模型名>.model.json`
2. `model.json`
3. `<模型名>.model3.json`
4. 目录下任意 `.model3.json`

找到入口后还会检查它引用的 `.moc3`（或 `model.json` 里的 `Moc` 字段）是否真实存在。资源缺失或不完整的模型会被跳过，并在构建输出里打印一行提示，避免出现在列表里点开却是空白。

开发模式下新增或删除模型配置文件会触发页面自动刷新。

## 录制说明

场景设置支持 16:9（960×540）和 9:16（540×960）。录制合成当前工程中的可见模型与背景，预览缩放、平移及选择框不影响输出。视频使用 MediaRecorder 导出为 WebM。
