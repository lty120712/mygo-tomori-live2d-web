# 版本发布记录

## v0.1 · 2026-10-12

原 v2.1 更名为 v0.1，开发分支同步更名为 `v0.1`。保存此前界面优化与编辑功能修复，移除 V1 编辑器、入口、专用组件、Arco UI 依赖及单模型工程迁移；删除本地及远端 `v1` 分支，保留历史发布标签。沿用多模型场景工程格式和本地存储键，已保存场景可继续恢复。


## v2.0.0 · 2026-10-11

v2 将单模型查看器扩展为多模型场景和多轨动画编辑器。

- 模型片段支持入场、离场、移动、裁剪、切割、复制粘贴及多选操作。
- 图层支持排序、重命名、锁定、隐藏，画布与轨道层级保持一致。
- 参数及位置、大小、旋转、透明度关键帧支持框选、拖动、右键编辑、批量删除、复制粘贴和缓动。
- 动作片段显示名称、进度和剩余时长，禁止重叠；表情切换帧保持到下一表情。
- 支持模型动作表情预览、独立鼠标跟随、原生参数和单项重置。
- 画布提供缩放旋转手柄、对齐吸附及辅助线、像素微调和一键重置位置大小。
- 时间线支持缩放、拖动播放头、吸附、整数时间码和 24/30/60 FPS。
- 支持撤销重做、循环预览、快捷键说明书、背景上传和完整场景录制。
- 工程支持本地恢复、导入导出，保留 v1 编辑器及 v1 数据。

验证：86 项测试通过，生产构建通过。动作任意时间的精确采样及音频多片段尚未实现，按原计划保留为后续工作。

发布分支：`v2`；标签：`v2.0.0`。

## v0.1 界面优化（原 v2.1）

从 v2.0.0 分出，原开发分支 `v2.1` 现更名为 `v0.1`，主要优化界面和信息层级，保留现有编辑功能及工程兼容。

- 参考暖灰、米白和酒红点缀的轻量视觉风格，统一圆角、图标、按钮及选中状态。
- 模型素材面板可折叠，以角色、服装／模型版本筛选和搜索替代长列表。
- 模型展示使用缩略图及可确认的中文名称，原始文件名作为辅助信息。
- 优化画布留白、属性分组、播放栏和时间线的视觉层级。

首个实施项：可折叠的模型素材筛选面板。

### 已完成：模型素材筛选面板

暖白色素材面板支持角色、服装、模型版本的联合筛选，中文／原始名称的多词搜索、结果数量、清除筛选及无结果提示。收起后显示窄栏入口，展开保留筛选条件；小窗口使用浮层展开。角色和可识别服装显示中文标签，未知素材保留原名；以对应模型的真实头像区分素材，完整文件名可悬停查看。场景已有素材轻量高亮，同一素材仍可重复添加。筛选和面板开关不写入工程或撤销记录。

验证：88 项测试通过，生产构建通过。页面验证 49 个素材的联合筛选、中文搜索、无结果清除、角色切换时无效服装条件清理、折叠条件保留；桌面收起扩大画布，小窗口浮层展开保持画布空间。完整界面配色与人物头像已在后续实施项中完成。

### 已完成：编辑器统一视觉

素材面板、顶部栏、画布周围、属性栏、播放栏、背景控件和时间线统一使用暖灰／米白与酒红点缀。共享主题变量覆盖按钮、输入框、选中与焦点、滚动条、图层状态、片段、动作表情及关键帧；变换与身体参数帧仍有独立颜色，右键菜单的 Teleport 节点和说明书同步配色。画布保持标准矩形直角，实际绿幕背景和录制尺寸保持工程设置。属性标题统一为简洁的分组标识，原有编辑逻辑沿用。

验证：88 项测试及生产构建通过；页面检查各区域实际配色、右键菜单、说明书滚动、关键帧颜色和空格播放暂停。600px 小窗口没有页面横向溢出，说明书保持在视口内；测试模型与关键帧已撤销。

### 已完成：模型真实头像

素材卡片显示对应服装模型的默认姿态头像，包含眼镜等版本差异。可见素材按需串行生成，收起素材库或播放时暂停新的生成任务；头像缓存在内存和本地数据库中。生成使用独立模型实例，并隔离清理，避免影响场景中的人物。

### 已完成：属性栏分页与列表

右侧分为基础、动作、表情、参数四页，切换保留当前页与列表选择。图层名称可直接编辑，模型中文身份展示在名称下，原始模型路径放入悬停提示。基础页集中片段时间、变换、复制和切割；动作与表情使用可搜索、可高亮选择的列表，保留预览、倒计时、重置和添加到时间线。参数沿用模型分组，可折叠，搜索时展开命中组，清空后恢复折叠状态；逐项重置和关键帧操作沿用。分页支持左右方向键与 Home / End，播放或图层锁定时可切换查看，编辑控件禁用。

验证：88 项测试及生产构建通过；浏览器检查动作搜索与预览倒计时、表情预览及重置、参数搜索与折叠、分页方向键切换，无新增控制台错误。

### 已完成：关键帧速度曲线

变换与身体参数的关键帧支持线性、二次／三次缓入、缓出、缓入缓出及自定义三次贝塞尔曲线。时间线“速度曲线”与关键帧右键菜单均可进入编辑器，拖动控制点、方向键或百分数输入调整，提供变化速度预览。横轴为时间、纵轴为变化进度，曲线斜率决定变化速度。应用作用于所选帧到下一帧，多选批量应用；末帧没有后续区间时提示。取消不产生修改，应用可撤销重做。复制粘贴、刷新和工程导入导出保留自定义曲线；旧缓动维持原有三次行为。

验证：92 项测试覆盖预设数学、自定义横轴求解、极端控制点、倒向参数、批量编辑、剪贴板独立快照、工程往返及撤销重做。页面验证预设／自定义实际插值、控制点拖拽与键盘微调、数值即时更新、右键入口和刷新保存，无新增控制台错误。

### 已完成：播放与时间线工具整理

播放控制、时间定位与录制入口分组，录制时显示独立状态。总时长、FPS、背景色与背景图片集中到“场景设置”，沿用工程编辑和撤销逻辑。时间线按选择、所选片段、关键帧与视图分组，并隐藏无选择时的关键帧剪贴板按钮；控件在窄窗口换行，时间线自动保留至少一条模型轨道与标尺空间。展开参数关键帧后，非线性区间显示缓动名称与区间范围，点击名称直达曲线编辑器；区间背景不拦截空白区域的框选操作。

验证：场景设置修改与撤销、曲线区间编辑入口、桌面及窄窗口换行检查通过。600px 窄窗口下工具栏无横向溢出，轨道区保留约 99px 可用高度。92 项测试和生产构建通过。

### 已完成：画布多选与批量变换

Shift 单击追加或取消人物，空白处拖动框选，Shift 框选追加，空白单击清空。多选显示人物虚线框及共用手柄；整体拖动、方向键微调保持间距，缩放与旋转围绕选区中心，保持人物比例及相对关系。每个模型按各自源时间记录自动关键帧，已有动画的属性继续记录当前帧；一次拖动或长按合并为一步撤销重做，并恢复选择。锁定、隐藏及当前未显示的人物不参与，右侧属性仍编辑主选人物。

验证：98 项测试通过，生产构建通过；页面检查框选、Shift 切换、整体移动与缩放、整组旋转、批量自动关键帧及一步撤销。测试包含共同边界约束、旋转越界的原子拒绝和不同源时间偏移。

### 已完成：多人对齐与分布、竖屏画布

多人选中时显示六种对齐、水平／垂直等距及整组居中。对齐基于旋转后的外框，分布固定两端并均分外框间隙，至少三人可用；整组居中保持人物间距。只修改相应位置属性，沿用自动或已有关键帧规则，一次点击一步撤销重做。播放禁用、录制隐藏，越界整组禁用。

恢复 v2 遗漏的 9:16 入口：场景设置支持横屏 16:9（960 × 540）和竖屏 9:16（540 × 960），实际合成画布、预览比例、选框、鼠标坐标及边缘吸附同步尺寸。录制跟随实际画布，工程保存比例并支持撤销；旧工程默认横屏，切换保留人物变换及关键帧。

验证：104 项测试通过，生产构建通过；页面验证多人对齐、三人等距、整组居中、一步撤销、竖屏完整画面及录制导出。导出 WebM 的视频元数据为 540 × 960。

### 已完成：画布与时间线多选联动

画布与时间线共用模型片段选择，同步高亮模型片段与图层；画布仅为当前可见且未锁定人物绘制选框，时间线保留未入场、已离场及隐藏片段的选择。两侧复制粘贴、Delete 使用相同模型集合，工具栏显示数量；粘贴、删除和撤销同步恢复模型选择。Esc 与空白点击清空选择。关键帧、动作和表情保持独立操作优先级，画布模型选择清除这些细项选择，输入框保留原生行为。补齐画布原生复制粘贴事件，修复片段内部关键帧空白区单击提前清空模型选择导致 Ctrl / Shift 追加失效的问题。

验证：页面检查画布框选同步、时间线 Shift 追加与 Ctrl 取消、整组复制粘贴删除和撤销、原生粘贴事件、关键帧 Delete 不误删模型、Esc 清空。现有 104 项测试和生产构建通过。

### 已完成：参数轨道顺序稳定与卡片折叠

参数分轨按固定属性顺序显示，当前参数只改变高亮，不再置顶；当前模型查看过的无帧变换属性保留行，避免切换时其他参数上下跳动。单击模型图层左侧卡片名称或空白区，切换展开／收起全部参数分轨，Enter 同样操作；卡片内按钮保持独立，图层拖拽不触发折叠。

验证：真实模型的“张嘴”“左眼开闭”来回点击，分轨顺序保持一致；左侧卡片连续单击展开、收起、重新展开，参数行和关键帧保留。生产构建通过。

### 已完成：身体参数帧低优先级

确认 SDK 的 setParams 在动作与表情更新之后强制写入，原实现会让身体帧盖掉素材。现在采集新旧格式动作的参数 ID 和眨眼／口型效果，并读取已加载表情的参数 ID；显式动作或表情控制的同名参数不再由身体帧强制覆盖，不相关参数继续生效。保留 SDK 的动作／表情叠加与淡入淡出，覆盖不修改工程帧数据；高优先级效果结束或移除后，身体帧重新生效。属性栏仍显示身体帧保存值。

验证：107 项测试通过，生产构建通过；真实便装模型同时播放微笑动作、大笑表情与嘴眼身体帧，100% 张嘴帧没有盖掉闭嘴微笑，0% 左眼帧没有盖掉素材的睁眼。表情移除、动作结束后恢复张嘴与闭左眼。测试包含旧参数别名、新旧 SDK 表情参数和动作间接效果。

### 修复：动作结束恢复身体状态

自动配套表情增加联动标识，随对应动作结束；旧工程同帧同名配套按联动识别，动作结束恢复之前的独立表情及当前身体帧。新手动添加、编辑、粘贴的表情标为独立，保留原持续规则；工程往返保留标识，编辑动作起点时配套表情跟随。动作终点后的清理不再只限播放状态，暂停定位也恢复；直接预览自然结束时清理动作姿态并重新应用时间线状态。

验证：110 项测试通过；真实便装模型实际播放愤怒动作到终点，以及直接预览结束后，均恢复张嘴 100%、左眼闭合。覆盖联动期限、旧工程兼容、之前独立表情恢复、手动表情保持及工程往返，生产构建通过。

### 已完成：画布预览缩放模块

将适应宽度、完整画面整合到固定的画布缩放工具栏，提供 10%–200% 滑块、比例显示及 100% 原始工程尺寸入口。支持方向键和 Home / End，手动调整退出自动模式，缩放保持当前视野中心；超出预览区时可双向滚动。选框在工程画布边界裁切，避免产生额外空白滚动区。仅影响预览，不改变工程尺寸、人物参数或录制输出，不进入撤销历史。

验证：页面检查横屏 10% 为 96 × 54、100% 为 960 × 540、200% 为 1920 × 1080；竖屏分别为 54 × 96、540 × 960、1080 × 1920，实际源画布尺寸保持原始值。两个适应模式及双向滚动均正常，生产构建通过。

### 已完成：画布平移

空格按住加左键、中键和缩放栏“平移”手形工具可拖动预览视野。平移捕获在预览区，优先于人物拖动、框选和手柄，松开结束并显示抓手光标；只改变滚动位置，工程、关键帧和撤销记录保持。录制时禁用，失焦与释放空格清理临时状态。空格播放／暂停改在松键时触发，期间使用平移则消费播放操作，长按不重复切换，输入框与对话框保留原生行为。

验证：113 项测试及构建通过。实际手形拖动使滚动量增加水平 100、垂直 60 像素，人物位置、关键帧数量与撤销状态不变。页面检查空格平移手势与中键按下不误播放，空格单击仍能播放暂停；状态测试覆盖多次拖动、重复按键、取消与普通左右键隔离。

### 修正：仅中键平移，适应窗口时也可移动

按用户反馈移除空格拖动和左键手形模式，空格恢复按下时播放暂停。中键平移改为预览画面偏移，不再依赖滚动条是否有可滚动空间，因此完整画面或适应宽度也能移动；预览偏移不改变工程或录制输出。缩放计算保留偏移中心，点击两个适应模式清除偏移重新取景。录制与失焦清理中键状态。

验证：112 项测试通过，覆盖仅中键识别、无滚动空间的双向偏移及起点计算；中键释放清理、空格播放暂停和构建检查通过。
