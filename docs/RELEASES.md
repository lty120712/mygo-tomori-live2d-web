# 版本发布记录

## v0.1 · 2026-10-12

### 修复：背景轨道添加交互与自动填充

「＋纯色」改为弹出颜色面板（9 个预设色块 + 自定义颜色 + 「用这个颜色添加」），原来占位的色块输入框位置换成「＋图片」：列出素材库里的图片，可直接添加或导入新图片。修掉一个真实缺陷：`＋纯色` 之前把 `{kind,color}` 对象当成颜色字符串传给片段创建，校验失败后一直回落到默认绿幕，所以「选什么颜色都是绿幕」。两种片段默认 5 秒，播放头到下一个背景片段或工程结尾不足 5 秒时自动填充剩余时长；播放头落在已有片段内部（含片段起点）时拒绝添加并提示。背景优先顺序不变：背景片段 → 场景设置里上传的旧背景图 → 场景设置兜底色。

验证：156 项测试与生产构建通过。浏览器验证预设蓝色实际写入片段与画布、5 秒默认、到工程结尾自动填充为 4 秒、夹在两个片段之间自动填充为 1 秒、片段起点添加被拒绝、「＋图片」导入并生成 1 秒图片背景片段，控制台无错误。

### 已完成：工程存储迁移到统一 IndexedDB

工程自动保存不再使用 `localStorage`，改写入浏览器 IndexedDB：新增 `src/localStore.js` 统一打开数据库 `tomori-assets`（版本 2，`assets` 素材仓库 + `documents` 文档仓库），素材库与工程文档共用这个数据库。首次打开时如果数据库里没有工程，会读取一次旧的 `tomori-scene-v2` 并在写入成功后删除它；之后完全不再读写 localStorage。数据库升级被其它标签页的旧连接占用时立即报错并提示关闭后刷新，读不到数据库时改为暂停自动保存并提示导出备份，避免用空工程覆盖已保存内容。同时修掉背景迁移在编辑被拒绝时留下无人引用的重复素材，以及离页保存改为页面隐藏 / 离页时立刻写入。

验证：155 项测试与生产构建通过。浏览器验证导入工程后刷新恢复、删除片段后刷新仍是新状态（旧 localStorage 数据不再被读取）、素材导入与图片背景仍走新数据库、legacy 背景图迁移只新增一个素材、被拒绝的背景编辑不再新增素材、场景设置确认旧背景图字段已清空，控制台无错误。

### 已完成：M3 背景图层

时间线最下方新增固定的背景轨道，按播放头切换纯色与图片背景，图片拉伸铺满整个画布；片段可拖动、裁剪、吸附、右键编辑并一步撤销，重叠与越界会被拒绝。画布与录制共用 `backgroundAtTime` 解析背景，没有被片段覆盖时依次回退旧背景图片与场景设置兜底色，空工程与旧工程画面保持不变。第一次编辑背景时，上传过的旧背景图片会进入素材库并只填补空档，旧字段清空，与本次编辑同属一步撤销。图片背景计入素材引用保护，背景片段上限 64 个并随工程 v4 读写。

验证：146 项测试与生产构建通过。浏览器验证背景行渲染、按时间切换纯色/图片、缺失素材回退兜底色、重叠拒绝、右键删除与移动到播放头、素材引用保护、刷新后恢复，以及纯背景工程录制导出 20 KiB WebM；控制台无错误。指针拖拽与菜单取色器受浏览器自动化限制未实测，其几何与校验逻辑由单测覆盖。范围与限制见 [M3 实施记录](superpowers/plans/2026-10-12-background-track.md)。

### 已完成：M2 普通图片轨道

图片素材可添加为独立片段，与模型穿插叠放，支持变换关键帧、吸附、图层管理、混合多选、复制粘贴、裁剪切割和撤销。图片按实际宽高生成选框与缩放锚点，并参与合成录制；v4 工程读写图片引用及动画，缺失素材保留片段并提示。图片解码结果按素材复用、移除后释放。补上离页保存，避免编辑后立即刷新丢失最后一次修改。

验证：135 项测试及生产构建通过；浏览器验证图片编辑、混合叠放、锁定隐藏、撤销恢复和纯图片录制下载。范围与限制见 [M2 实施记录](superpowers/plans/2026-10-12-image-tracks.md)。

原 v2.1 更名为 v0.1，开发分支同步更名为 `v0.1`。保存此前界面优化与编辑功能修复，移除 V1 编辑器、入口、专用组件、Arco UI 依赖及单模型工程迁移；删除本地及远端 `v1` 分支，保留历史发布标签。沿用多模型场景工程格式和本地存储键，已保存场景可继续恢复。


### 已完成：动作任意时间精确采样

动作改为按源时间曲线离屏精确采样，播放、暂停、任意跳帧、反向与重复定位都直接求值该帧姿态，不再依赖 SDK 实时播放推进。现代 SDK 在隔离参数缓冲上驱动离屏 updateParameters；旧模型读取 MTN 源曲线，按采样率插值并支持非整数源帧与淡入淡出。表情单独叠加到采样缓冲，不污染真实模型参数。动作或表情释放后的参数先恢复默认值，直到身体关键帧接管，避免旧表情队列泄漏到姿态。说明书重构为分页多章手册。

验证：115 项测试及生产构建通过；浏览器验证任意跳帧改姿态、同一播放头两次渲染逐字节一致，动作／表情采样与说明书分页无控制台错误。

### 已完成：素材库三分类与本地素材存储

左侧素材库改为模型 / 图片 / 音频三个分类。图片与音频以 Blob 存入浏览器本地（IndexedDB，请求持久化存储），支持逐个导入、列出与删除，跨工程复用；单文件上限图片 64MB、音频 512MB。模型分类保留原有筛选与添加。工程格式升级到 v4，旧工程打开时自动补齐新字段。

验证：素材库纯函数与存储接口单测通过，生产构建通过；浏览器验证图片 / 音频导入、刷新后保留、删除与模型筛选无回归，无控制台错误。


## v2.0.0 · 2026-10-11

v2 将单模型查看器扩展为多模型场景和多轨动画编辑器。

- 模型片段支持入场、离场、移动、裁剪、切割、复制粘贴及多选操作。
- 图层支持排序、重命名、锁定、隐藏，画布与轨道层级保持一致。
- 参数及位置、大小、旋转、透明度关键帧支持框选、拖动、右键编辑、批量删除、复制粘贴和缓动。
- 动作片段显示名称、进度和剩余时长，禁止重叠；表情切换帧保持到下一表情。
- 支持模型动作表情预览、独立鼠标跟随、原生参数和单项重置。
- 画布提供缩放旋转手柄、对齐吸附及辅助线、像素微调和一键重置位置大小。
- 时间线支持缩放、拖动播放头、吸附、整数时间码和 24/30/60 FPS。
- 支持撤销重做、循环预览、快捷键说明书、背景上传和完整场景录制。
- 工程支持本地恢复、导入导出，保留 v1 编辑器及 v1 数据。

验证：86 项测试通过，生产构建通过。动作任意时间的精确采样及音频多片段尚未实现，按原计划保留为后续工作。

发布分支：`v2`；标签：`v2.0.0`。

### 已完成：身体参数帧低优先级

确认 SDK 的 setParams 在动作与表情更新之后强制写入，原实现会让身体帧盖掉素材。现在采集新旧格式动作的参数 ID 和眨眼／口型效果，并读取已加载表情的参数 ID；显式动作或表情控制的同名参数不再由身体帧强制覆盖，不相关参数继续生效。保留 SDK 的动作／表情叠加与淡入淡出，覆盖不修改工程帧数据；高优先级效果结束或移除后，身体帧重新生效。属性栏仍显示身体帧保存值。
