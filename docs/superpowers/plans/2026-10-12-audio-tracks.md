## 约定

- 音频片段上限 32 个，轨道编号 0–7；同一轨道禁止重叠，不同轨道可同时出声。
- 片段字段：`{ id, assetId, name, track, start, duration, offset, volume, fadeIn, fadeOut }`；`volume` 0–1，`fadeIn` / `fadeOut` 按秒且不超过片段时长。
- 时间只由纯函数决定：`audioGainAt` 给当前音量，`planAudioPlayback` 给「素材内起播秒数 + 剩余时长 + 剩余淡入淡出窗口」，因此跳帧与循环回绕都只是重新计算。
- 默认片段时长取素材本身的长度并截断到工程剩余时长；新增片段落在该音频行对应的轨道，粘贴近乎优先复用复制来源的轨道、被占用时自动换到第一条空闲轨道。
- 音频只在播放时出声；暂停、跳帧会停掉现有音源。

## 验证

- `npm test`：173 项通过，新增 17 项（音频纯函数 7 项、调度引擎 7 项、v4 往返与校验 3 项）。
- `npm run build`：通过；保留既有大包体积提示。
- 浏览器（自动化作用域只读，用 DOM 可访问性树 + 截图取色 + 文件字节扫描代替肉眼与听感）：
  - 导入 3 秒测试音频（素材卡显示 3.0 秒），加到音频轨道 1，再在轨道 2 叠放同一素材，行标签与片段块时间码正确。
  - 播放时播放头推进到 00:01:20、出现「暂停」按钮、没有「缺失或无法解码」提示（证明 WAV 解码成功），控制台无错误。
  - 右键设置音量 50%、淡入 0.5 秒、淡出 0.5 秒后片段标题显示对应数值。
  - 录制导出 83 KiB WebM，文件头同时含 `V_VP9` 与 `A_OPUS`（含 `OpusHead`），说明音频轨已混入导出。
  - 未覆盖：指针拖拽移动 / 裁剪手柄（浏览器自动化无法派发指针手势），几何与校验由 `planClipMove` / `applyClipStarts` / `editTimelineClip` 单测覆盖。
