# 普通图片轨道（M2）实施记录

承接已完成的 M1 素材库。范围来自 [素材轨道设计](../specs/2026-10-12-media-tracks-design.md)；背景轨道、音频调度和素材打包留待后续阶段。

## 完成项

- [x] 图片素材旁添加「＋」，在播放头创建独立片段，可重复使用同一素材。
- [x] `mediaTracks.js` 提供模型与图片的统一编辑视图，工程仍分别保存 `clips` 和 `imageClips`。
- [x] 图片与模型共用图层排序、重命名、锁定、隐藏、框选、多选、复制粘贴、裁剪、切割和撤销重做。
- [x] 图片按源宽高生成选框、命中区域、缩放锚点、旋转外框和吸附参考，支持混合多选变换与对齐。
- [x] 图片支持位置、缩放、旋转、透明度关键帧与缓动；移动和切割保留源时间；修改 FPS 同步转换关键帧。
- [x] 合成画布按统一图层顺序绘制模型与图片，透明区域保留；录制复用同一合成画布，纯图片工程也可录制。
- [x] 解码缓存按素材复用；片段移除或工程切换时释放 bitmap，迟到的异步结果也会释放。
- [x] v4 读取并验证图片数据；素材缺失不丢弃片段，显示缺失提示，预览和录制跳过，导出时告知。
- [x] 当前工程仍引用的素材禁止直接删除。工程 JSON 不包含素材文件，界面和说明书明确提示。
- [x] 浏览器离页时同步保存，修复最后一次修改尚在防抖等待中便刷新而丢失的问题。

## 约定

- 每个工程分别限制 16 个模型片段、64 个图片片段；视觉图层编号共用 0–79。复制或切割超限时整批拒绝。
- 图片片段额外保存原始 `width` / `height`，避免本地素材缺失后选框尺寸改变。
- 图片 100% 按原始比例缩小至不超过 960×540；不放大小图，横竖工程共用这个参考尺寸。
- 图片保留空 `params` / `events` 作为通用片段编辑接口；导入只接受五种变换关键帧，不接收模型参数和事件。

## 验证

- `npm test`：135 项通过，包括新增 11 项图片与混合片段回归测试。
- `npm run build`：通过；保留既有大包体积提示。
- 浏览器：透明 PNG 导入、添加、位置关键帧中间帧插值、画布拖动、缩放旋转、切割撤销、立即刷新保存、锁定保护、隐藏、模型图片前后叠放、混合复制粘贴及一步撤销。
- 工程导出：确认图片素材引用、尺寸、图层顺序、变换和关键帧写入 JSON；工程往返与缺失引用保留另有单测。
- 纯图片录制：生成约 105 KiB 的 WebM 文件，正常到达工程终点并退出录制；浏览器无错误日志。未对导出视频逐帧比对。
- 浏览器测试使用独立 `localhost:5174` 存储，与原有 `127.0.0.1:5174` 工程分离。
