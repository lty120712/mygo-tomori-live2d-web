# 稳定性收尾、M5 与工程素材包

2026-10-13，已实现。

- 保存：documents 仓库中 scene 与 scene:revision 同一事务读写。每个页面使用读取时的版本；版本不一致暂停本页自动保存并提示先备份、再刷新。页面无编辑时不在隐藏或关闭时重复写入。同页保存请求串行处理。非版本冲突的保存失败保留待保存状态，隐藏或关闭页面时会再试一次。
- 音频：播放时安排当前和未来片段；暂停、跳帧、销毁使旧异步请求失效。播放与首次录制先准备解码和混音流；循环先更新播放头再安排音频。
- M5：素材库多文件选择与文件拖入、逐项进度与失败明细；音频以多声道最大峰值生成 2048 桶波形，元数据存于统一 IndexedDB。旧音频首次显示时补算。波形按源偏移与片段时长截取。
- 工程格式统一：导入、导出仅使用 .tomori 原始二进制包，包含工程设置与引用的图片、音频并去重；移除 JSON 文件导入、导出分支。导入验证清单、长度与引用，重新分配素材 ID；素材导入中途失败回收本次新增素材。内置模型不随包分发。清单长度、素材数量、重复 ID 与引用一致性都会校验，损坏的包在改动当前工程之前就被拒绝。
- 顺带补齐音频素材引用保护，当前工程引用的音频不能直接从素材库删除。

验证：194 项自动测试及生产构建通过；在 5175 隔离来源实测多文件分类、波形生成、两个页面保存冲突、工程包下载，在第二个空素材库来源恢复图片和音频。未播放直接录制得到 WebM，其 EBML Tracks 包含视频类型 1 与音频类型 2。后台浏览器录制检查有明显等待延迟，不能据此保证实时播放性能或逐帧音画精度。文件拖入通路已实现，本轮未使用实际系统拖放验证。

回归补充（同日第二轮）：在隔离来源逐项走查图片片段删除 / 撤销 / 复制粘贴 / 播放头切割、背景片段纯色添加与颜色选择、背景复制粘贴与切割、音频右键音量与淡入淡出、音频复制粘贴、四条轨道的静音 / 独奏 / 隐藏 / 独见、Delete 键删除四类片段、场景设置比例 / 时长 / 帧率、播放暂停与逐帧定位、循环开关、时间线缩放与画布缩放预设、说明书弹窗、模型片段加载与动作表情添加、变换关键帧，以及编辑后刷新的持久化，控制台无错误。新增工程包清单校验与波形缓存两组边界测试；拖动落库时机仍由 `planClipMove` / `editTimelineClip` 单测覆盖（浏览器自动化无法合成指针拖拽）。

同日第三轮补上音频节拍：`src/audioBeats.js` 从已缓存的峰值推导节拍点（局部极大值 + 自适应阈值 + 最小间隔合并，间隔过近保留更响的，上限 400 点，时间取到微秒以避免浮点噪声），素材节拍由 `assetStore.beats` 从波形派生并只在内存里记一次，删除素材即失效。音频片段的波形区域成为定位区：拖动波形定位播放头，标签条仍移动片段，两端仍裁剪；标尺定位与片段移动、裁剪都把节拍时间并入吸附目标，工具栏新增「节拍吸附」开关。验证：203 项测试与生产构建通过；在 5175 导入 3 秒点击音频后片段出现 5 个节拍标记，节拍右侧 4px 点击波形使播放头精确落在 75%（00:07:15），关闭开关后同一位置落在 73%（00:07:09）且标记消失；拖动波形只动播放头、拖动标签条把片段从 60% 移到 70%、在波形高度拖动左裁剪把手仍只改裁切入点；控制台无错误。测试用的 3 秒点击音频留在素材库中，可随时用素材卡片的 × 删除。

同日第四轮补上音频滤镜与音量关键帧：滤镜是接在片段增益之后的单个双二阶滤波器（`src/audioFilters.js` 的 5 个预设，无滤镜时不建节点），播放链路变成 source → gain → filter → master。音量关键帧（`src/audioVolume.js`）用「素材内秒数」做坐标系，与片段 offset 同一套换算，所以移动片段不用改关键帧、裁剪只让窗口外的关键帧不再显示；最终音量 = 总音量 × 淡入淡出 × 包络，没有关键帧时与旧行为逐位一致。右键菜单可添加 / 更新 / 删除 / 清空关键帧并指定缓动，时间线上以菱形显示，上下拖动改音量、左右拖动改素材内时间（横向吸附节拍）；切割按切点拆分关键帧并在两侧补切点关键帧，跨切点的斜坡听感不变；复制粘贴带走滤镜与关键帧。调度把包络折成 setValueAtTime / linearRampToValueAtTime 序列（缓动区间补 6 个插值点），跳帧与循环回绕后重算。同时修掉波形节拍请求失败后不再重试的问题（请求标记改为 finally 释放）。验证：217 项测试与生产构建通过；在 5175 整页重载后走查右键菜单、添加/拖动/删除关键帧、滤镜应用、带滤镜与关键帧播放、逐步撤销，控制台无错误，测试改动已还原。

同日第五轮补上视频素材轨道：素材库新增「视频」分类，导入时探测宽高、时长并抽取首帧缩略图（统一 IndexedDB），素材卡与时间线片段显示首帧。视频与图片共用图层、画布变换、变换关键帧、裁剪切割、复制粘贴与撤销；画布按播放头 seek 并绘制，播放时跟随，离开片段或隐藏图层时暂停并回退到背景轨道。工程 v4 增加 `media: 'video'` 并按类型分别限流，素材缺失时片段保留并提示、预览与录制跳过。模型资源仍使用应用内置资源，不提供模型导入导出。验证：236 项测试与生产构建通过；在 5175 导入 10 秒 WebM 后切割成 3:00 / 6:29 两段、复制粘贴保时长、Delete 删除、播放头正常推进、隐藏后画面回退背景，控制台无错误。
