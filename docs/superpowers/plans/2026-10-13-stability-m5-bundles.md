# 稳定性收尾、M5 与工程素材包

2026-10-13，已实现。

- 保存：documents 仓库中 scene 与 scene:revision 同一事务读写。每个页面使用读取时的版本；版本不一致暂停本页自动保存并提示先备份、再刷新。页面无编辑时不在隐藏或关闭时重复写入。同页保存请求串行处理。非版本冲突的保存失败保留待保存状态，隐藏或关闭页面时会再试一次。
- 音频：播放时安排当前和未来片段；暂停、跳帧、销毁使旧异步请求失效。播放与首次录制先准备解码和混音流；循环先更新播放头再安排音频。
- M5：素材库多文件选择与文件拖入、逐项进度与失败明细；音频以多声道最大峰值生成 2048 桶波形，元数据存于统一 IndexedDB。旧音频首次显示时补算。波形按源偏移与片段时长截取。
- 工程格式统一：导入、导出仅使用 .tomori 原始二进制包，包含工程设置与引用的图片、音频并去重；移除 JSON 文件导入、导出分支。导入验证清单、长度与引用，重新分配素材 ID；素材导入中途失败回收本次新增素材。内置模型不随包分发。清单长度、素材数量、重复 ID 与引用一致性都会校验，损坏的包在改动当前工程之前就被拒绝。
- 顺带补齐音频素材引用保护，当前工程引用的音频不能直接从素材库删除。

验证：194 项自动测试及生产构建通过；在 5175 隔离来源实测多文件分类、波形生成、两个页面保存冲突、工程包下载，在第二个空素材库来源恢复图片和音频。未播放直接录制得到 WebM，其 EBML Tracks 包含视频类型 1 与音频类型 2。后台浏览器录制检查有明显等待延迟，不能据此保证实时播放性能或逐帧音画精度。文件拖入通路已实现，本轮未使用实际系统拖放验证。
