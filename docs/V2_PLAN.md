# v2 场景与多轨编辑器

历史 v1 保存在标签 `v1.0.0`（提交 `b2153d2`）；v2 发布保存在 `v2` 分支和 `v2.0.0` 标签。原 v2.1 已更名为 v0.1，当前分支为 `v0.1`，详见 [发布记录](RELEASES.md)。

## 核心约定

- 模型目录是素材库；添加素材生成独立模型片段，同一资源可重复添加。
- 轨道管理片段，片段决定入场、离场；不同轨道可以同时显示。
- 全局播放头统一驱动场景。片段内部使用本地帧，移动片段携带内部动画。
- 裁剪使用源时间偏移，切割保留原动画时间，不重新计时。
- 参数、变换关键帧和动作、表情事件归属于片段。
- 模型实例各自有 SDK 与 canvas。最终合成画布用于预览和录制。
- 工程沿用现有多模型场景存储键与格式；旧单模型工程迁移已移除。

## 实施与验收

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| 1 | 多实例渲染、片段时间、轨道、选择、移动裁剪、统一时钟 | 两个角色独立编辑；重叠同屏，区间外隐藏 |
| 2 | 参数与变换关键帧、动作表情事件、工程往返、合成录制 | 片段移动携带动画；导出完整场景 |
| 3 | 动作精确时间采样、音频多片段、撤销重做、吸附与时间线缩放 | 任意跳帧与导出逐帧一致 |

阶段 3 中撤销重做、时间线缩放与吸附已完成；动作精确采样、音频多片段尚未实现。时间线提供 1×、2×、4×、8×、16× 缩放及“适合全长”；标尺、片段、事件与关键帧共用横向滚动区域，轨道卡片固定在左侧。按钮 / 滑条围绕可视区域中心缩放，Ctrl / ⌘ + 滚轮围绕鼠标位置缩放。片段移动的两端及裁剪边界在 8 像素范围内吸附到播放头、其他片段首尾或工程首尾；默认开启，可用开关或按住 Alt / Option 暂时关闭，黄色线提示已吸附。缩放和吸附开关不写入工程历史，拖动仍合并为一步撤销。

阶段 1、2 的基础版已经实现。浏览器实测双模型同屏、时间区间隐藏、复制删除、切割源偏移、边缘裁剪、原生参数编辑、工程往返和合成录制。录制抽帧验证：灯 0–5 秒，爱音 3–8 秒；1 秒只有灯、4 秒同屏、6 秒只有爱音。

多实例需要额外处理 l2d 2.1.1 的 Cubism 6 全局释放行为：适配器只释放当前模型资源，不能销毁其他实例共用的 Framework。SDK 升级时复核此适配层。

SDK 的实时动作播放不等于任意时间采样。应先验证并实现各代动作采样，再承诺动作精确跳帧；参数与变换关键帧由项目时钟直接求值。

## 撤销与重做（已实现）

关键帧采用片段内菱形概览：变换与身体参数分两排，不再依赖滚动到底部才发现位置动画。同时间同类别的多个参数合并显示，悬停列出参数和值；点击选择片段及时间，展开对应参数轨。“位置 X”等属性可在固定关键帧栏查看当前数值、相邻帧时间与值、前后定位、增删和改值。参数轨位于所选模型轨道下方，当前属性优先；菱形可拖动改时间，保持值及缓动、不覆盖相邻帧、不越过裁剪后的可见区间。Delete 在菱形获得焦点时仅删除该参数关键帧，所有修改可撤销重做。时间线上沿可拖动调整高度，在画布空间与轨道可见数量之间自行选择。

v2 背景支持上传图片、移除图片和重置为绿幕（默认色 #00b140）。图片按画布尺寸铺满，预览与录制共用合成画布；上传时最长边限制为 1920，图片以 WebP 数据存入工程，随工程导入导出和本地恢复。背景操作支持撤销重做，图片载入完成前暂停播放和录制。

时间标尺与轨道空白处支持按住拖动播放头，拖动期间捕获指针，移出轨道仍持续定位并限制在工程范围。片段单击选中后，删除按钮显示在对应轨道左侧卡片；Delete 仅在选中且未播放、录制时删除，输入框内不触发。删除后清空选择，支持撤销恢复片段与选择。片段拖动仍用于移动，边缘拖动仍用于裁剪。

动作与表情支持独立实时预览，与“添加到时间线”分开。预览不修改工程和撤销记录；结束预览、切换片段、定位时间、播放或编辑时恢复时间线状态。每个模型片段拥有鼠标跟随开关，默认打开，保存到工程并支持撤销重做。合成画布指针按各片段的位置、缩放、旋转换算，控制实际存在的头部和眼球参数，已设置关键帧的同名参数优先；鼠标移动本身不写入关键帧或编辑历史。预览期间放开参数覆盖以展示 SDK 动作，暂停画布仅对该预览实例持续更新。

选择动作后显示资源中的时长（动作组有多个候选时取最长）；读取失败显示未知时长。独立提供“重置动作”（停止预览动作，恢复模型原生默认姿态，不额外播放素材里的 idle 动作）和“重置表情”（默认表情），仅影响实时预览，不删除时间线事件。关闭鼠标跟随或鼠标离开窗口时明确写回头部、眼球默认值，避免 SDK 保留最后朝向；已有同名关键帧仍优先。

画布按可用空间自适应放大，侧栏可单独收起；顶部“放大画布”收起侧栏与时间线，“返回编辑”恢复布局。录制分辨率仍为 960×540。各现代模型实例使用独立动画计时，避免共享 SDK 计时影响后加载模型的动作与表情预览。

顶部按钮及 Ctrl+Z、Ctrl+Shift+Z / Ctrl+Y 操作当前 v2 工程。覆盖添加、复制、切割、删除、移动和裁剪片段，名称、参数、单项重置、关键帧、动作表情事件、背景、总时长、FPS 和导入工程。

一次画布或时间线拖动、一次输入框编辑合并为一步。重置的撤销同时恢复当前帧关键帧和预览参数；撤销后产生新编辑会清空重做。历史最多保留 100 步，仅在当前编辑会话中保存；刷新或切换编辑器后重新开始。播放、录制、选择片段和定位时间不生成编辑历史。播放及录制中禁用撤销重做；输入框内保留原生文本快捷键行为。

动作和表情时间线剪辑已接入：事件保存独立 ID、源入点 offset、源长度 sourceDuration 和播放长度 duration（秒），事件起点仍使用模型源帧。动作左右边缘裁剪，移动按帧对齐，支持边界吸附、右键时间码编辑、Delete、复制粘贴及一步撤销重做。表情仅有切换帧，始终延续到下一表情或模型结束，旧时长字段忽略；没有进度、倒计时和裁剪，同帧编辑或粘贴替换原表情。表情在后一个表情开始时切换；动作禁止重叠且必须完整放入模型片段，相邻动作可首尾相接。旧重叠动作恢复时显式保留之前的有效范围并保留源长度。动作片段内有播放进度和剩余时间，独立动作预览同样有倒计时；相同起点禁止冲突，粘贴校验模型资源兼容及可见范围。播放从裁剪源入点开始，并在有效出点停止动作，支持现代和旧版 SDK。暂停时仍不承诺任意动作帧的精确采样。

图层排序已接入：track 0 为最上层，时间线从上到下与画布前后顺序一致；合成从底到顶绘制，点击优先命中最上层。新建和复制模型插入顶层。左侧轨道卡片支持上下拖动，卡片及模型片段右键支持向上一层、向下一层；排序将同轨道全部片段作为一组移动，其他动画数据不变，一次排序为一步撤销重做。图层顺序使用既有 track 字段随工程保存。

图层名称独立于层级，默认使用模型名称，可双击或右键重命名。整层锁定与隐藏已接入左侧按钮和右键菜单：锁定禁止移动、裁剪、参数、关键帧、动作表情编辑、删除及该层排序，画布命中跳过锁定模型；隐藏从场景合成（含录制）中排除模型。状态保存在 layerName、layerLocked、layerHidden，同轨道片段保持一致，切割和上下排序保留状态，兼容旧工程默认解锁且显示。撤销重做覆盖这些状态修改，说明书已同步。67 项测试及生产构建通过，浏览器验证锁定保护、播放、隐藏与撤销恢复。

模型片段多选已接入：Ctrl / Shift 点击追加或取消；轨道空白处框选模型，关键帧条及参数子轨仍框选关键帧，选择类型互斥。拖动任一选中片段整体移动，按帧对齐、保持时间间隔，整组边缘吸附播放头与其他片段，Alt 临时关闭；工程边界和同轨道未选片段限制整组位移。Ctrl+C / Ctrl+V 复制粘贴全部动画数据，最早片段对齐播放头，新图层插到顶部并保留相对顺序，跨帧率转换关键帧与事件；超出时长或 16 个模型上限整批拒绝。Delete 及左侧删除按钮批量删除。锁定片段跳过多选，所有批量修改原子校验，一次拖动/删除/粘贴一步撤销重做。72 项测试通过；浏览器验证多选、框选、移动吸附、复制粘贴、删除及撤销，以及关键帧删除不误删模型。

时间轴右键菜单已统一：轨道、模型片段、关键帧、动作、表情和参数子轨各有明确分支和分组，快捷键右侧显示，锁定状态及禁用项一致，模型/关键帧/事件选择使用蓝色高亮。多选模型菜单显示数量，关键帧操作作用于全部所选片段；播放头批量切割仅处理所选且被播放头经过的片段，超出 16 个上限原子拒绝。动作菜单有时长/源入点，表情仅切换时间，事件子轨粘贴按类型禁用。菜单按实际尺寸定位并支持长菜单滚动。菜单全选关键帧清空模型选择，防止 Delete 误删模型；离散菜单动作先结束进行中的编辑，避免锁定/解锁与删除合并撤销。73 项测试通过，浏览器验证菜单分类、锁定禁用、双模型切割、全选/清空关键帧和独立撤销恢复。

画布变换与定位已接入：四角等比缩放并固定对角，顶部圆形旋转手柄，Shift 旋转吸附到 15°。拖动模型在预览 8 像素范围内吸附画布中心、边缘和其他可见模型的中心及旋转后外框；黄色 DOM 辅助线提示对齐，Alt 临时关闭。隐藏模型不参与对齐，锁定模型仍作为参考。点击画布获得焦点后方向键移动 1 个输出像素，Shift 移动 10 像素，长按连续微调；时间线和输入框保留既有按键行为。拖动和微调共用变换关键帧、图层锁定、播放录制保护及历史记录，一次拖动或长按一步撤销。失焦、窗口失焦和编辑状态改变结束微调历史；辅助线和手柄不进入录制输出。79 项测试及生产构建通过，页面验证中心吸附、1/10 像素微调、关键帧记录与撤销、时间线焦点区分和锁定保护，测试场景已清理。

画面变换新增“重置位置和大小”：X/Y 归零、缩放恢复 100%，旋转、透明度及身体/动作/表情不变。按属性分别判断当前源帧：命中关键帧则更新该帧，位于两帧之间则插入重置帧，无关键帧只恢复基础值（不受自动添加开关影响），已有关键帧范围之外不改动动画。保留其他帧与缓动，重置先结束输入/拖动历史，再形成独立一步撤销；非可见片段、锁定、播放与录制保护沿用编辑器。83 项测试与生产构建通过，浏览器验证基础值恢复、帧间新增及撤销恢复插值，测试片段已撤销。

循环播放已加入播放工具栏，默认关闭，状态仅保留当前编辑会话、不写入工程历史。开启后按工程总时长循环，跨帧率及后台延迟仍保持相位，末尾直接回到开头而不输出空白终点帧。循环时恢复模型默认姿态并清空动作/表情播放缓存，再由当前工程时间重新驱动；暂停继续沿用当前位置，播放中关闭循环在当前轮末尾停止。录制覆盖循环开关，只录制完整工程一次，开关在录制期间禁用。86 项测试及生产构建通过，页面验证末尾循环后保持播放、暂停，以及关闭后定位末尾停止。测试后已返回开头并关闭循环。
